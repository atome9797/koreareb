# 일본 자료 CSV 양식

API 가 없는 일본 자료는 이 양식에 맞춰 CSV 로 만든 뒤 앱의 **시장분석 › 데이터 수집** 탭 또는 **일본점검** 화면에서 가져온다.
명령줄로는 `market_data.py import-competition`, `jp_fraud.py import` 를 쓴다.

- 머리글은 일본어 그대로 두는 것을 권장한다. 한국어·영어 머리글도 받는다 (예: `募集戸数` = `모집호수` = `supply_units`). 괄호 속 단위는 무시한다.
- 인코딩은 UTF-8(BOM 있어도 됨), Shift_JIS(Excel 기본), EUC-KR 을 차례로 시도한다.
- 날짜는 `2026-08-01`, `2026/8/1`, `20260801`, `令和8年8月1日`, `R8.8.1` 을 받는다. 회차·판매기는 `2026-08` 처럼 연월.
- 금액은 숫자만 남기고 읽는다 (`1,896,000円` → 1896000). `平均価格(万円)` 처럼 머리글에 万円 이 있으면 만 엔 단위로 본다.

## 1. 공영주택 응모 결과 — `jp_public_housing_competition.csv`

구청·도청이 공개하는 抽せん倍率 표를 옮긴다 (예: 練馬区 「抽せん倍率」 페이지의 申込番号·住宅名·入居人数·募集戸数·応募数·倍率).

| 열 | 뜻 | 필수 |
|---|---|---|
| 募集回 | 모집 회차 (연월) | ✓ |
| 事業主体 | 都営 / 区営 / 市営 / 公社 등 | |
| 都道府県コード, 市区町村コード | 2자리 / 5자리. 모르면 都道府県 이름도 된다 | 지역 분석에 필요 |
| 住宅名 | 주택(단지) 이름 | ✓ |
| 区分 | 家族向·単身者向·シルバーピア, 또는 入居人数 | |
| 募集戸数, 応募数 | 모집 호수, 응모 수 | ✓ |
| 倍率 | 비워도 된다 (응모 ÷ 모집으로 다시 계산) | |

| 열 | 뜻 | 필수 |

## 3. 공영주택 신청자 — `jp_public_housing_applicants.csv` (개인정보)

| 열 | 쓰는 규칙 |
|---|---|
| 募集回, 申込番号 | 필수. 같은 회차·번호는 다시 가져오면 갱신된다 (점검 결과는 유지) |
| 住宅名, 区分 | 区分에 単身者向/家族向 이 들어가면 단신·가족 요건을 본다 |
| 氏名, 生年月日 | 같은 사람 중복 신청 |
| 電話番号, メール, 住所 | 같은 주소·연락처를 쓰는 다른 세대 |
| 市区町村コード | 지역 (없으면 住所로 찾는다) |
| 都内転入日 | **都内로 전입한 날** (都内에서 이사한 날이 아님). 신청 직전 전입, 단신 3년 거주 요건 |
| 世帯人数, 世帯変更日 | 세대 인원과 신청 구분, 신청 직전 세대 변경 |
| 世帯所得, 障害者等世帯 | 소득 기준 (세대 인원별 상한, `config/jp_rules.json`). 障害者等世帯 는 都営住宅 **특별 구분**(60세 이상·장애인·고교 졸업 전 자녀가 있는 세대 등)이면 1 — 더 높은 상한을 쓴다 |
| 現住居 | 持家·公営住宅 이면 주택 곤궁 요건 확인 |
| 申込日 | 기간 계산의 기준 |

## 4. 신축 맨션 신청자 — `jp_new_condo_applicants.csv` (개인정보)

| 열 | 쓰는 규칙 |
|---|---|
| 販売期, 申込番号 | 필수 |
| 物件名, 住戸番号 | 한 물건 여러 호실 신청 |
| 氏名, 生年月日, 法人名 | 같은 명의·법인의 여러 호실, 법인 신청 |
| 電話番号, メール, 住所 | 연락처·주소 공유 (명의 대여 의심) |
| 購入目的, 本人居住 | 投資·賃貸·転売 이거나 본인 거주 아님 |
| 契約名義 | 신청 명의와 다르면 표시 |
| 引渡前売出 | 계약 뒤 인도 전에 매물로 나왔으면 Y |
| 申込日 | |

규칙의 근거와 가중치는 `krjp/jp_rules.py` 머리말과 `config/jp_rules.json` 에 있다. 위험 점수는 먼저 볼 신청자를 고르는 참고값이고 판정이 아니다.
